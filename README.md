This project initially started as a small idea: sell books from Italian book sellers to Ebay, for an upper price. Arbitraging, in other words. Why are people buying the same thing for more? We don't know.

The project currently lays in a non-usable state for the most part, as external dependencies have changed: the scrapers are not all working.

I made some money out of this, but not enough to prioritize it more, and then decided to focus on personal life & career rather than this one project, so I decided to park/end it.
